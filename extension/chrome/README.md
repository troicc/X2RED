# Chrome extension

1. Start X2RED on `http://127.0.0.1:8787`.
2. Open `chrome://extensions`.
3. Enable Developer mode.
4. Choose **Load unpacked** and select `extension/chrome`.
5. On an X post, click the extension icon or use **Send to X2RED** from the context menu.

The extension sends no cookies and performs no background scraping. It only opens the local intake form with the current page URL.
