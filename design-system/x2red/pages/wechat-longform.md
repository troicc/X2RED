# 公众号长文工作台 · 页面覆盖规则

> 继承 `../MASTER.md`。这里只记录公众号长文生产线与工作区的页面级差异。

- **Updated:** 2026-08-08
- **Density:** 6/10 · **Motion:** 2/10

## 1. 生产线不是说明书

- 五个阶段始终可见，但阶段导航只展示编号、名称、动作和文字状态。
- 读取、产出、模型 / Skill 与优化位置只在当前查看的阶段详情中展开，禁止把五套长说明同时塞进五张等宽卡片。
- 系统当前阶段使用 `aria-current="step"`；用户正在查看的阶段使用独立选中态，两者不能混为一谈。
- 选中历史成品时，“已选成品”是上下文状态，不是正在查看的阶段；顶部必须同时写清“正在查看阶段 N/5”和“已选成品 · 公众号 vN”。成品只使用结果态，不冒充 `aria-current="step"`。
- 点击阶段先查看详情；详情中的明确动作再定位到表单、编辑器、深度写作项目或发布预览。
- 深度写作已有项目时必须打开现有项目，不能把用户带回“新建深度写作”的起点。

## 2. 阶段感知工作区

- 尚无公众号版本时，材料输入是核心任务：使用全宽两栏材料编排，隐藏无意义的空编辑器和空预览。
- 生成版本后，材料区退为可折叠辅助栏，编辑器成为主工作区；排版完成后再突出预览与发布包。
- 打开旧成品后必须有首屏可见的“开始新文章”逃生口。该动作只清除当前项目/版本选中，保留历史成品、主来源和已选材料；存在未保存编辑时先确认，随后展开材料区、聚焦阶段 2 的创建动作。
- 为新文章切换主来源时，不得自动打开该来源的第一个旧成品；用户只能通过明确的历史版本选择重新进入旧成品。
- 输入区的主动作固定在表单末尾，不覆盖内容，不在全页滚动时形成漂浮遮挡。
- 可选粘贴材料默认折叠，库内材料选择保持直接可见；紧凑视口的预生成态不得自动折叠整个材料区。
- 库内来源、已写版本和粘贴材料继续保持加法输入；视觉重排不得改变 evidence、provenance 或不可变版本合同。

## 3. 响应式与可访问性

- ≥981px：五阶段同排；阶段详情采用“判断说明 + 三项 I/O/优化 + 路由/动作”。
- 861—980px：五阶段仍同排，详情和材料表单改为单列，避免辅助区挤压主任务。
- ≤860px：阶段导航使用局部横向、可吸附的紧凑阶段轨道，I/O 技术细节按需展开，避免五张说明卡把主任务推到数屏之后。
- ≤680px：详情事实卡、状态和主动作改为单列并占满可用宽度。
- 所有阶段和动作最小触控目标 44px；长模型名允许换行，不产生页面级横向滚动。
- 平滑定位遵守 `prefers-reduced-motion`，禁用时改为即时定位。
