# 统一创作任务与视觉工作流 · 页面覆盖规则

> 继承 `../MASTER.md`。这里只记录 UI1 的任务向导、旧工作台交接和视觉候选审稿差异。

- **Updated:** 2026-08-30
- **Density:** 5/10 · **Motion:** 2/10

## 1. 导航是六组入口，不是一次性重写

- 顶层固定为 `收集 / 创作 / 视觉 / 发布 / 资产与偏好 / 设置` 六组；信号台、原料库、语料池、小红书、公众号、发布、池子记忆、写作偏好和设置等旧入口全部保留在对应组内。
- “创作任务”和“视觉工作流”是渐进式协调层，不能复制旧工作台的生成、保存或发布实现。
- 旧 DOM ID 保持一个兼容版本；交接使用稳定事件和现有字段，不通过重复控制器抢占提交事件。
- 页面切换后聚焦主标题；返回时把焦点还给原导航按钮。移动抽屉继续支持 Escape、遮罩关闭和焦点回返。

## 2. 创作任务向导

- 六步依次为材料、文章类型、平台、读者与承诺、写作模式、视觉路线。任务在本地自动保存，并在页首持续显示已完成步数和当前目标。
- 材料必须来自统一来源体系；向导只冻结选择和意图，不替代语料池批次、evidence pack 或工作台中的事实门禁。
- 每步有可见标签、说明和即时校验。步骤 tab 使用键盘左右方向键切换，错误同时提供文字提示和焦点定位。
- 完成后只向小红书、公众号长文、公众号轻内容或深度写作发送明确的 handoff；目标工作台仍负责最终表单校验、生成和不可变版本保存。

## 3. 视觉工作流

- 系列总览先显示页面数、候选数、已选数和发布就绪数；每项标签与数值必须形成独立语义单元，不能按两行错位排列。
- 页面/槽位导航与 Contact Sheet 使用渐进披露。选中页后才加载其 Prompt provenance、完整 Prompt、Prompt diff、候选状态和审核动作。
- 候选卡同时显示编号、缩略图、质量分、明确状态和重复警告。选择、保留、驳回或修复不得删除其他候选或其 provenance。
- Prompt 重复和图片 hash 重复使用文字警告；风险不能只靠颜色。缺少真实候选时显示可操作空状态，不伪造分数或图片。
- 批量上传沿用现有逐页回传 API 和候选生命周期；视觉页不直接发布，也不绕过本地中文排版、版权、水印、事实和人工审核。

## 4. 响应式与验收

- 1360px：紧凑全局导航与双列视觉检查区；主要阅读/编辑区保持 `minmax(0, 1fr)`。
- 860px：全局导航变为抽屉，向导、系列总览、页导航、候选和 Prompt 面板全部单列；页面本身不得横向滚动。
- ≥1500px：内容宽度受控居中，候选网格增加列数但不拉长文本行。
- 所有交互目标至少 44px；长指纹、错误、文件名和 Prompt 可换行或在自身区域滚动。
- 自动化必须覆盖六组入口与全部旧入口、向导交接、焦点恢复、方向键、视觉候选状态、860/1360/宽屏、减少动态效果和 console/page error。
