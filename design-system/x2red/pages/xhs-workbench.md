# 小红书工作台 · 页面覆盖规则

> 继承 `../MASTER.md`。这里只记录来源选择、工作台级归档、来源阅读、判断抽屉和紧凑桌面布局的页面级差异。

- **Updated:** 2026-08-06
- **Density:** 4/10 · **Motion:** 2/10

## 1. 壳层和来源栏必须可恢复

- 主导航收起按钮必须直接存在于根 HTML，不依赖运行时脚本创建；脚本只负责状态同步和交互增强。
- >1360px 默认 256px；861—1360px 默认 76px 图标栏；≤860px 为带遮罩、Escape 关闭、焦点回返和主内容 `inert` 的抽屉。
- 76px 状态仍显示 44×44px 的“展开主导航”按钮，不能把恢复入口和导航标签一起隐藏。
- 选中来源后，来源箱自动收为 64px，并常驻“展开来源箱”按钮；用户本轮手动展开后不得被 MutationObserver 立即收回。

## 2. 来源栏必须可读、可归档且语义准确

- 平台筛选使用一个带可见标签的全宽选择器，不把十个平台标签横向挤在约 300px 的来源栏内。
- 每条来源只保留一个平台/来源组徽标。语料池批次使用“语料池批次”和“冻结批次”，不显示 X 图标、`X SOURCE` 或 X 原文链接；只有真实 X 来源才使用 X 语义。
- 来源名称省略而不换成逐字堆叠，摘要最多显示有限行；底部元信息允许换行，但不得与按钮重叠。
- 单条“归档/恢复”按钮与“打开来源”是两个独立点击区域，按钮最小高度 44px。来源箱提供“待处理/本台归档”，选中来源的粘性工具栏也提供相同动作。
- 小红书工作台的归档只写入 `SourceWorkbenchState(workbench=xhs)`，不得改变 `SourceItem.workspace_state`，也不得让来源从公众号长文、公众号轻内容或深度写作消失。彻底删除必须保持独立、明确且危险的全局动作。

## 3. 正文是主任务

- 来源阅读区始终使用一个 `minmax(0, 1fr)` 主列；不得再把正文、“我的判断”和“来源素材”并排成三个永久列。
- 选中来源标题栏在 ≤1600px 分两行：作者信息占第一行，全局删除、风格选择和“AI 分析并生成”在第二行形成右对齐动作组；工作台归档常驻正文粘性工具栏，不再挤入作者标题行。
- 动作组中的短按钮不被压成逐字换行；选择器保留可读宽度，所有控件仍满足 44px 目标。
- 导入区在 ≤1360px 改为单列，避免输入、类型、媒体开关和主动作互相挤压。

## 4. 判断与素材按需出现

- “我的判断”和“来源素材”放入一个按需打开的侧抽屉，而不是永久占用正文宽度。
- 桌面抽屉宽度为 `min(400px, 视口宽度 - 48px)`，自身滚动；手机左右留 16px。
- 触发按钮使用 `aria-expanded`；抽屉使用 `role="dialog"` 和 `aria-modal="true"`，打开后聚焦关闭按钮，Tab 保持在抽屉内，Escape/遮罩/关闭按钮均可退出并把焦点还给触发按钮。
- 抽屉打开时冻结主内容滚动，但不销毁编辑内容。

## 5. 验收基线

- 1280×720：主导航 76px、来源栏 64px、正文阅读区约 1023px、判断抽屉 400px。
- 来源栏展开约 300px 时，平台选择器全宽；来源卡片不横向溢出，单条归档/恢复按钮保持 44px 高。
- 语料池批次的列表和阅读器都没有 X 标识；归档后只从小红书“待处理”消失，在“本台归档”可恢复，同时公众号来源选择仍保留它。
- 主导航可在 76px 和 256px 间往返，展开不会遮挡正文，收起不会丢失恢复入口。
- 页面 `scrollWidth` 不得大于 `clientWidth`；正文标题不得退化为一两个英文单词一行。
- 切换来源、打开/关闭判断抽屉和收起/展开两级侧栏时，console 不得出现 error 或 warning。
