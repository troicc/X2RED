# 公众号轻内容工作台 · 页面覆盖规则

> 继承 `../MASTER.md`。这里只记录轻内容模式、视觉回传和长页面导航的页面级差异。

- **Updated:** 2026-08-29
- **Density:** 5/10 · **Motion:** 2/10

## 1. 模式必须真正隔离

- “长文编辑”和“轻内容图组”是同一公众号入口下的两个互斥 tab，不是上下堆叠的两个页面。
- 轻内容激活时，长文生产线、长文材料区、编辑器和预览全部退出布局；不得只隐藏其中一块并留下长文阶段说明。
- 页面 kicker 和说明随模式切换，轻内容只解释任务、文案、视觉和交付四步。
- tab 使用 `role="tablist"`、`role="tab"`、`aria-selected`、可见焦点和方向键切换；非当前 tab 从顺序焦点中退出。

## 2. 长页面导航合同

- 桌面全局侧栏固定在视口，内容列表只在侧栏内部滚动；页面滚到视觉分镜或交付阶段时，全局入口和收起按钮仍然可见。
- 侧栏展开宽度 256px、收起宽度 76px。收起后顶部必须显示明确的“展开主导航”按钮，不能把唯一恢复入口一起隐藏。
- 861—1360px 默认紧凑，但允许临时展开；≤860px 继续使用带遮罩、Escape 关闭和焦点返回的抽屉。
- 轻内容四阶段局部轨道只负责当前任务，不替代全局导航。

## 3. ChatGPT 网页生图回传

### 冻结视觉简报

- production 分镜卡片显示“冻结 PageVisualBrief”、三候选数和主编已选择状态；不再用一个自由视觉隐喻字段代替整个画面决策。
- 展开页可编辑职责、具体主体、动作/关系、场景、视点、裁切、光线与读者情绪；evidence refs 只读显示，不允许用空值绕过。
- 页检查器同时显示选中简报、layout、evidence refs 和可展开的 Visual Bible 不变量。历史 legacy 版本才显示旧“视觉隐喻”。
- 窄屏下简报字段单列，标题/候选状态纵向排列，长 evidence ref 可换行；不得产生页面横向滚动。

- 网页版 ChatGPT 是人工交接，不得被包装成隐藏 API，也不得自动接管登录态、点击生成或抓取用户成图。
- 每页顺序固定为：冻结当前不可变分镜 → 用统一文本 compiler 编译并直接显示完整无字 3:5 Prompt → 人工检查并复制 → 用户在 ChatGPT Images 生成并保存 → 回传 PNG/JPEG/WebP → X2RED 本地排中文并重建预览。
- 网页 handoff 可以调用与 API render 相同的文本 compiler，但绝不调用图片 API；视觉模型只提供 raw anchor，中文、页码和最终版式继续由本地合成。
- 未生成时不得把“复制 Prompt”显示为可用主动作，也不得用“保存并渲染”误导用户；应显示明确的编译入口、空状态和“不调用图片 API”说明。生成后完整 Prompt 常驻只读文本框，复制、打开 ChatGPT Images 和上传依次解锁。
- Prompt 面板必须显示 compiler mode、Skill version、完整 recipe、warnings、source/Prompt fingerprint、重新编译动作和 Prompt diff。溯源字段采用渐进披露但 mode/warning 不得隐藏；降级用 `DEGRADED_FALLBACK` 明文和 `role=alert`，不能只靠黄色边框。
- 回传前若 phrase、note、evidence、视觉职责、文章主旨、Visual Bible 或其他 source fingerprint 输入变化，旧 Prompt 立即视为过期，必须重新编译和复制。
- 过期状态必须立即禁用复制、外链和上传，并在 Prompt 面板与折叠详情中同时显示文字原因；不能等到上传时才报错。
- 新图组允许逐页回传；只有 3—6 页全部具有 raw anchor 和 final poster 后才提供发布 ZIP。
- GLM/兼容图片接口保留为明确标注的备用路径，不能与“不接 API”的网页回传混写。

## 4. 状态与风险

### 本地排版配方诊断

- 页检查器在存在 V4 composition diagnostics 时显示“本地排版配方 · 中文模式名”，不能只暴露内部英文枚举。
- 首行固定说明画布比例、可见文字区域数、无溢出和主体未遮挡状态；安全状态必须用文字表达，不能只靠绿色。
- 字体角色、字重、字号比、行高、字距和避让变换使用现有紧凑 chip，不新建第二套卡片或颜色系统。
- selection reason 常驻可读；发生 fallback 时必须明示来源模式并提示人工复核，不能把 `safe_zone_caption` 伪装成主动艺术选择。
- 无 diagnostics 的历史版本不显示空卡，仍保留 raw/final、旧版提示和重合成边界。

- 显示“已复制 Prompt”“可回传”“本页已本地排版”“整组已打包”等文字状态，不能只靠颜色。
- 编译等待期间使用现有全局 busy 状态禁用重复提交并更新 `aria-busy`；主动作保持至少 44px，长指纹可换行，diff 可滚动，≤680px 溯源表改为单列。
- 保存文章标题、摘要或正文后，既有逐页短句和说明必须保持不变；不得偷偷从正文连续切句重排分镜。
- 四页短句/说明不得同页重复、跨页重复或形成“本页说明 = 下一页短句”的接龙。页检查器同时展示当前页取材依据和来源引用，让用户能判断四页是否真的使用了不同语料线索。
- 原始视觉锚点和最终海报并排可检查；重新排版不得调用图片模型。
- 上传限制为 12 MB、最小 240×240、最大 5000 万像素；最终仍需人工检查异常字符、水印、平台标识和版权。
- 不宣称网页模型一定无水印，也不宣称 Prompt 能绝对阻止模型生成文字。
